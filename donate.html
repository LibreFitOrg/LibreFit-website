Let's build it together ❤️

LibreFit is a passion project, built by one person who believes software should be open, simple, beautiful, and above all, respectful of your privacy.

I pour countless hours into designing, coding, and refining every detail to create the best possible experience. It's a commitment to you, the user, and to a better digital world.

LibreFit is only possible with your support, whether by donating or by contributing to code or translations. Check GitHub to know how to contribute to the project. If you want to donate instead, see below.

All donators and contributors get the supporter version and a credit in the app and on GitHub.
